# Checkpoint Initialisation Projet crm-nil

- **Date** : 03/09/2026
- **Objectif** : Initialisation d'un projet vierge (`crm-nil`) avec l'ensemble des compétences (skills), des règles, des équipes de développement virtuelles et du schéma d'orchestration g-stack importés depuis le projet `WORK`.
- **Fichiers clés configurés** :
  - `AGENTS.md` & `.agents/AGENTS.md` : Organisation de l'équipe de dev (Lead/CTO, Product, Frontend, Backend, QA, DevOps).
  - `CLAUDE.md` : Aide-mémoire IA, commandes et catalogue complet des skills g-stack.
  - `.agents/rules/` : Règles de design Apple HIG (`apple-design.md`), suivi de contexte continu (`mem-cp.md`), cartographie de code (`graphify.md`), investigation data (`recherche-colis-edi.md`).
  - `.agents/skills/` : Skills projet dont `apple` et `gstack`.
  - `.agents/workflows/` : Workflows rapides (`/no-apple`, `graphify`).
  - `skills_library.md` : Bibliothèque globale de référence des ~1486 skills activables à la demande.
- **Statut** : Prêt pour le démarrage du développement.
