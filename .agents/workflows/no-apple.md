# Workflow /no-apple

Desactive la regle absolue de design Apple HIG pour la demande actuelle.

## Usage
Commencer n'importe quel message par `/no-apple` :
`/no-apple cree un tableau bootstrap classique sans effets de verre`

## Effet
Lorsque `/no-apple` est present en debut de requete, l'agent contourne la regle Apple HIG et applique uniquement le style, framework ou consigne specifique demandee.
